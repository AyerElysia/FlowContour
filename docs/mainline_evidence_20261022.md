# FlowContour 主线迁移的近期证据快照

证据截止：2026-10-22 16:59（北京时间）。这是固定历史快照，不是实时训练状态，也不是当前 VerSe 主线的性能表。统一名称为 FlowContour、CR-MoE、GDPO；历史数据不因更名改变。

## 1. 固定 BTCV 评价口径

- 全部 847 张切片等权的联合前景 Dice，失败保留，不改为实例／器官加权以抬高数值。
- GT box 与 GT class，Memory off，推理 seed20260731。
- 两步完整位移，每步 4 次原 V5 求值；无 frac，零 latent，推理关闭额外探索。
- 逐器官 Dice、多尺度 NSD 及实际轮廓图用于补充解释，不能替换主指标。

BTCV 实验与当前主线的 MoonViT＋CR-MoE VerSe、真实 AB2 和 latent scale 1.0 并非同一模型／推理协议。下面的迁移依据不直接证明新主线有效。

## 2. 已完成的主要对照

变化均为 Dice 百分点，即 `100 × (候选 − 对照)`。

256 点追加训练的 12 个病例均改善；切片等权差值的病例聚类 95% 区间为 `[+0.7270, +1.4171]` 百分点。此前相同 8000 步预算下，128 点约 0.909006，256 点约 0.903696；这份负结果保留。没有 128 点 18000 步的匹配对照，不能把训练预算收益归因于点数。

50/20/30 混合状态采样和两步完整位移是近期采用的实验协议；本表没有将它们各自相对所有旧协议的收益单独识别出来，不能把在线模仿的全部改善归因于取消 frac。

## 4. 新奖励与尚待回答的问题

新 `NSD@1/2/4/8px` 等权奖励在本快照时尚未完成两组训练后的固定评价。对同一旧策略的 296 个候选重新评分时，8px 单项约 65.5% 满分，组合组内标准差由旧尺度的 0.01842 降至 0.01334。这仅说明容差更宽且可能压缩分差，不是训练收益证据。

以下问题仍需新的匹配实验回答：

1. 50/20/30 状态覆盖与完整位移推理如何迁移至 MoonViT＋CR-MoE VerSe。
2. 两步 GDPO 是否在在线模仿之后带来稳定且实际有意义的增益。
3. 大幅局部单峰／单谷在完整预算、多种子下是否优于低频对照。
4. 去掉 0.5px、加入 8px 是否改善训练，而非仅提高或饱和奖励数值。
5. 256 点在匹配预算和成本下是否值得替换 128 点默认值。
6. 新阶段条件、严格概率重放和完整恢复能否在新主线中一致通过验收。
